# @farcasterorg/miniapp-sdk

Build onchain social apps

## Installation

```bash
pnpm add @farcasterorg/miniapp-sdk
```

Or include via a CDN and access via `miniapp`:

```
<script src="https://cdn.jsdelivr.net/npm/@farcasterorg/miniapp-sdk/dist/index.min.js"></script>
<script>
  miniapp.sdk.actions.ready();
</script>
```

## Documentation
